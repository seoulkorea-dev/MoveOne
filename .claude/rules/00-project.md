# 프로젝트 범위와 도메인

## 서비스
MoveOne — 수도권(서울·경기·인천) 한정 통합 멀티모달 이동 서비스. 모바일 웹(폰 브라우저)이 1차 타깃이고, 추후 Capacitor로 감싸 앱스토어·플레이스토어에 배포한다.

## 1차 범위 (이 범위 밖은 구현하지 않는다)
- s1 인증: 회원가입(이메일 필수), 로그인, 로그아웃, 비밀번호 재설정
- s2 경로 검색: 출발/도착 입력 → 경로 후보 목록 → 경로 상세
- 교통수단: 대중교통 + 도보만

## 1차 제외
s3 예약·결제, s4 실시간 도착정보, s5 이동 이력, s7 운영자 콘솔, 시외버스, 수도권 외 지역, 네이티브 앱.

## 확인된 제약 (설계 시 반드시 고려)
- ODsay는 멀티모달 **조합** 경로를 만들어주지 않는다. 조합 엔진은 직접 구현한다.
- ODsay는 지도를 제공하지 않는다. 노선 그래픽 데이터만 준다 → 지도는 카카오맵 JS SDK.
- ODsay는 접근성·실시간·결제 정보를 주지 않는다.
- ODsay 호출 한도가 문서에 없다 → 캐시를 전제로 설계한다.
- ODsay와 공공데이터포털의 정류장 ID 체계가 다르다 → ID 매핑 테이블이 필요하다.
- 카카오는 2026-07-21 정책 변경으로 계정당 첫 앱만 무료 쿼터 → 앱은 하나만 만들어 공유한다.

## 역할
일반 이용자, 교통약자, 운영자, 제휴 관리자. 1차는 일반 이용자만 구현하되 스키마에는 role을 남겨둔다.
